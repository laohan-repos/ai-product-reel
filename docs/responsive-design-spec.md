# AI Product Reel PC 与移动端设计规范

> 本文档定义 AI Product Reel 的视觉语言、响应式规则，以及 PC 和移动端核心页面布局。
>
> 配套文档：
>
> - [产品需求文档](./product-requirements.md)
> - [开发路线](./development-roadmap.md)
> - [页面交互说明](./page-interaction-guide.md)

## 1. 设计目标

AI Product Reel 是一个多步骤、长任务、多媒体密集型创作工具。界面需要同时满足以下目标：

- 专业：让用户相信复杂生成任务正在被可靠处理。
- 清晰：让用户随时知道当前作品、步骤、输入和输出。
- 高效：PC 端充分利用宽屏，减少频繁跳转。
- 易操作：移动端保留完整主流程，不只是结果查看器。
- 克制：视觉服务于素材和生成结果，避免装饰抢夺注意力。
- 可扩展：新增模型、步骤和媒体版本时不破坏整体结构。

## 2. 设计关键词

```text
清晰 / 专业 / 轻量 / 创作感 / 媒体优先 / 状态可见
```

视觉上采用偏中性的浅色工作台风格，以暖紫色作为品牌与主操作色。图片和视频是页面视觉主体，容器和装饰保持低对比度。

## 3. 响应式断点

| 名称 | 范围 | 主要设备 | 布局策略 |
| --- | --- | --- | --- |
| Mobile S | 320～374 px | 小屏手机 | 单列、紧凑间距 |
| Mobile | 375～767 px | 主流手机 | 单列、底部主操作 |
| Tablet | 768～1023 px | 平板、窄窗口 | 单列或双列、抽屉导航 |
| Desktop | 1024～1439 px | 笔记本 | 固定侧栏、内容网格 |
| Desktop L | 1440 px 以上 | 大屏显示器 | 限宽内容、增强预览区 |

### 3.1 内容宽度

- PC 主内容最大宽度：`1500px`。
- PC 页面左右安全边距：`24px`，大屏可增加到 `32px`。
- 平板页面左右边距：`20px`。
- 手机页面左右边距：`16px`。
- 320px 小屏可缩小到 `12px`。

### 3.2 布局切换点

- `< 1024px`：固定侧栏改为抽屉导航。
- `< 768px`：双栏表单、双栏媒体区改为单列。
- `< 640px`：弹窗改为接近全屏的底部面板或全屏页。
- `< 480px`：按钮组允许纵向堆叠，隐藏次要文字信息。

## 4. 设计基础

### 4.1 色彩系统

### 品牌色

| 名称 | 建议值 | 用途 |
| --- | --- | --- |
| Primary 600 | `#6D4AFF` | 主按钮、选中状态、品牌标识 |
| Primary 500 | `#7C5CFF` | 悬停、图标、进度高亮 |
| Primary 100 | `#EEE9FF` | 选中卡片背景、浅色提示 |
| Primary 50 | `#F7F4FF` | 大面积弱背景 |

### 中性色

| 名称 | 建议值 | 用途 |
| --- | --- | --- |
| Neutral 950 | `#17151D` | 主要文字 |
| Neutral 700 | `#494650` | 次级文字 |
| Neutral 500 | `#77737F` | 辅助文字 |
| Neutral 300 | `#D9D6DE` | 强边框 |
| Neutral 200 | `#E9E7EC` | 默认边框 |
| Neutral 100 | `#F3F2F5` | 控件背景 |
| Neutral 50 | `#FAF9FB` | 页面背景 |
| White | `#FFFFFF` | 卡片、弹窗 |

### 状态色

| 状态 | 前景色 | 浅背景 | 用途 |
| --- | --- | --- | --- |
| 成功 | `#15803D` | `#ECFDF3` | 已完成、连接成功 |
| 警告 | `#B45309` | `#FFF7E6` | 等待、前置不足 |
| 错误 | `#C53030` | `#FFF0F0` | 失败、删除操作 |
| 信息 | `#2563EB` | `#EFF6FF` | 说明、进行中 |

### 色彩规则

- 主色只用于关键动作、选中和流程进度。
- 危险色只用于失败信息和删除动作。
- 不只通过颜色表达状态，必须搭配图标或文字。
- 图片和视频区域可使用深色背景，其他区域保持浅色。
- 正文与背景的对比度应满足 WCAG AA。

### 4.2 字体

### 字体族

- 中文界面：系统中文无衬线字体优先。
- 拉丁字符：Geist 或系统无衬线字体。
- 代码、JSON 和提示词：Geist Mono 或系统等宽字体。

建议字体栈：

```css
font-family: Geist, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
```

### 字号层级

| 层级 | PC | 手机 | 字重 | 用途 |
| --- | ---: | ---: | ---: | --- |
| Display | 32px | 26px | 700 | 首页主标题 |
| H1 | 28px | 22px | 700 | 页面标题 |
| H2 | 22px | 19px | 650 | 功能区标题 |
| H3 | 18px | 17px | 600 | 卡片标题 |
| Body | 14px | 14px | 400 | 正文和表单 |
| Small | 12px | 12px | 400 | 辅助信息 |
| Label | 12px | 12px | 600 | 标签和状态 |

正文行高使用 `1.5～1.7`。Markdown 方案内容应提高到 `1.7`，避免长文本阅读疲劳。

### 4.3 间距

使用 4px 基础网格：

```text
4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64
```

### 常用间距

- PC 页面区块间距：`24～32px`。
- 手机页面区块间距：`20～24px`。
- 卡片内边距：PC `20～24px`，手机 `16px`。
- 表单字段间距：`16px`。
- 按钮与说明文字间距：`8px`。
- 媒体候选卡片间距：PC `16px`，手机 `12px`。

### 4.4 圆角与阴影

| 元素 | 圆角 |
| --- | ---: |
| 小标签、徽章 | 6～8px |
| 输入框、按钮 | 10～12px |
| 普通卡片 | 16px |
| 重点媒体卡片 | 18～20px |
| 弹窗 | 20～24px |

阴影保持克制：

- 普通卡片默认不使用明显阴影，以边框分层。
- 悬停卡片使用轻微阴影和边框变化。
- 弹窗、浮层和移动端底部面板使用中等阴影。
- 选中状态优先使用品牌边框和浅背景，不依赖阴影。

### 4.5 图标

- 使用统一线性图标风格。
- PC 常规图标尺寸：`16～18px`。
- 手机主操作图标尺寸：`18～20px`。
- 纯图标按钮必须提供可访问名称和 Tooltip。
- 同一动作在所有页面使用同一图标。

## 5. 栅格系统

### 5.1 PC 栅格

- 主区域使用 12 列栅格。
- 列间距：`20～24px`。
- 媒体预览与设置区常用 8:4 或 7:5 比例。
- 候选卡片可使用 3～4 列。
- 工作流主体卡片通常占满 12 列。

常见组合：

```text
8 + 4：主媒体预览 + 版本列表
7 + 5：表单配置 + 实时预览
6 + 6：参考内容 + 产品内容
4 + 4 + 4：三张候选结果
3 + 3 + 3 + 3：四张小型媒体卡片
```

### 5.2 移动端栅格

- 默认单列。
- 两张小型图片候选可以使用两列。
- 视频候选、表单和长文本必须单列。
- 横向版本列表可以使用横向滚动，但必须显示下一张卡片的一部分作为滚动提示。

### 6.1 顶部栏

- 高度：`64px`。
- 固定在页面顶部。
- 左侧显示 Logo 和产品名称。
- 中间显示当前作品名称，过长时截断。
- 右侧展示批量生成、模型设置等全局动作。
- 滚动时增加底部边框或轻微阴影。

### 6.2 侧边栏

- 图标模式宽度：`88px`。
- 展开模式宽度：`240px`。
- 页面空间不足时优先使用图标模式。
- 一级导航与工作流步骤分区展示。
- 当前项使用品牌色背景和文字。

### 6.3 主内容

- 顶部与顶部栏保持 `24px` 间距。
- 页面标题区与内容区保持 `20～24px` 间距。
- 最底部保留至少 `48px` 空间，避免内容紧贴窗口。

```text
┌──────────────────────────────┐
│ ☰  AI Product Reel      ⚙    │ 56
├──────────────────────────────┤
│ 作品名                       │
│ 当前步骤  6 / 10             │
│ [●━━━━━━○━━━━○]              │
├──────────────────────────────┤
│                              │
│ 页面内容                     │
│                              │
│                              │
├──────────────────────────────┤
│ [当前步骤主操作]             │ 可选固定操作区
└──────────────────────────────┘
```

### 7.1 移动顶部栏

- 高度：`56px`。
- 固定顶部并适配安全区域。
- 左侧为菜单按钮，中间为产品名称或作品名称，右侧为设置。
- 标题过长使用省略号，不换成两行。

### 7.2 导航抽屉

- 宽度为屏幕的 `82～88%`，最大 `360px`。
- 顶部展示产品信息与关闭按钮。
- 依次展示作品、素材库和十个工作流步骤。
- 底部展示模型设置和版本信息。
- 点击遮罩或关闭按钮退出。

### 7.3 移动步骤条

- 展示当前步骤名称和 `当前序号 / 总数`。
- 用简化进度条表达整体进度。
- 左右滑动或点击可打开完整步骤列表。
- 不在顶部同时展示十个文字标签。

### 7.4 底部主操作区

适用于生成、保存、合成等关键动作：

- 固定在底部安全区域上方。
- 高度约 `72～84px`。
- 白色半透明背景和顶部分隔线。
- 内容区增加底部 padding，避免遮挡最后一项内容。
- 只有当前页面存在明确主操作时才展示。

## 22. 状态组件

### 状态徽章

| 状态 | 文案 | 图标 |
| --- | --- | --- |
| 草稿 | 草稿 | 圆点 |
| 等待 | 等待处理 | 时钟 |
| 进行中 | 生成中 | 旋转图标 |
| 完成 | 已完成 | 勾选 |
| 失败 | 生成失败 | 警告或叉号 |

### 进度条

- 有真实百分比时使用确定进度条。
- 没有百分比时使用不确定进度动画。
- 批量任务展示完成步骤数，例如 `3 / 5`。
- 不根据等待时间伪造模型进度百分比。

## 23. 图片与视频规范

### 图片

- 产品图片默认使用 `object-fit: contain`，避免裁掉商品。
- 封面缩略图可使用 `cover`，但查看器必须展示完整图片。
- 加载失败时显示文件类型图标、文件名和重试。

### 视频

- 播放器默认黑色背景。
- 保持原始宽高比。
- 没有封面时显示首帧或中性占位。
- 同一页面只允许一个视频自动播放。
- 移动网络环境下不自动预加载所有完整视频。

## 24. 动效规范

- 页面与步骤切换：`160～220ms`。
- 弹窗和底部面板：`180～260ms`。
- 卡片悬停：`120～160ms`。
- Toast：进入 `180ms`，退出 `140ms`。
- 进度和加载动效保持柔和，不使用快速闪烁。
- 遵循用户的“减少动态效果”系统设置。

动效用于解释状态变化，不用于延迟用户操作。

## 27. 可访问性与可用性

- 所有可点击元素都要有明确的悬停、聚焦和按下状态。
- 键盘焦点顺序与视觉顺序一致。
- PC 弹窗打开后焦点进入弹窗，关闭后返回触发点。
- 手机底部面板打开后不能操作背景。
- 文字和状态不能被图片遮挡。
- 状态不能只靠红、绿颜色区分。
- 触控目标之间至少保留 `8px` 间距。
- 缩放到 200% 时主流程仍可操作。

## 28. Codex 实现建议

- 顶部栏。
- PC 侧边栏。
- 移动端导航抽屉。

- 按钮、输入框、卡片和状态徽章。

### 第三轮：业务页面

- 首页作品卡片。
- 素材库双栏与移动选择器。
- 工作台步骤导航。
- Generation、关键帧和视频候选卡片。

### 第四轮：复杂页面

- 模型设置。
- 提示词编辑器。
- 批量生成。
- 最终视频和剪映草稿。

### 第五轮：质量检查

- 320、375、768、1024、1440 和 1920px 截图对比。
- 键盘导航。
- 长标题、长错误和大量版本。
- 加载、空、失败和禁用状态。
- 减少动态效果和高缩放场景。

## 31. 设计完成标准

PC 与移动端设计完成后，用户应能在 320px 到 1920px 的常见视口内完成同一条核心创作流程。两端可以采用不同的空间组织方式，但功能、数据和任务状态必须保持一致。移动端不能仅保留浏览能力，PC 端也不能因为追求信息密度而牺牲状态清晰度和可访问性。
