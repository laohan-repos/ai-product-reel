# 同款视频（AI Product Reel）功能需求文档

> 用途：供用户了解产品功能，也可作为 Vibe Coding 时拆分任务、核对成果的依据。
>
> 范围：以当前工作台展示的六步创作流程为准。本文描述用户应当获得的体验；涉及 AI 模型或第三方服务的结果，取决于实际配置和服务能力。

## 1. 产品概述

用户上传一条参考视频和自己的产品图片，系统提取参考视频的画面与拍摄节奏，结合产品素材生成视频方案、关键帧和分镜视频，最后合成完整短片，或生成剪映草稿继续编辑。

产品主要面向电商运营、短视频创作者，以及希望体验 AI 视频制作流程的用户。当前版本按单用户、本地运行的方式设计。

## 2. 用户完成一次创作的流程

```text
准备素材 → 创建作品 → 生成参考视频预览图 → 生成产品预览图
        → 生成产品视频方案 → 生成并选择关键帧
        → 生成并选择分镜视频 → 合成 MP4／生成剪映草稿
```

作品工作台展示六个步骤：

| 步骤 | 名称 | 用户得到的结果 |
| --- | --- | --- |
| 1 | 抽帧合成参考视频预览图 | 一张按时间顺序展示参考视频画面的总览图 |
| 2 | 合成产品预览图 | 一张展示多张产品图片的总览图 |
| 3 | 生成我的产品视频方案 | 包含生成段、画面描述、时长和配音内容的方案 |
| 4 | 生成产品分镜关键帧 | 每个生成段可选择的图片版本 |
| 5 | 生成分镜视频 | 每个生成段可选择的视频版本 |
| 6 | 合成视频 | 完整 MP4 成片，或用于后续编辑的剪映草稿 |

## 3. 功能模块

### 3.1 作品管理

**用户目标：** 将不同产品或不同创意的制作过程分开管理。

功能要求：

- 创建作品，填写作品名称并进入独立工作台。
- 在作品列表查看名称、状态、当前进度、已完成视频段数和更新时间。
- 重命名作品；删除作品前进行二次确认。
- 返回已有作品时，恢复该作品的预览图、方案、关键帧、分镜视频和成片记录。
- 不同作品的生成结果相互隔离，素材库中的原始素材可供不同作品使用。

验收要点：创建或修改作品后刷新页面，数据仍然存在；删除一个作品不会删除其他作品。

### 3.2 素材管理

**用户目标：** 为创作准备可复用的参考视频和产品图片。

功能要求：

- 创建“同款素材组”，每组包含一条参考视频和一组产品图片。
- 上传、预览、重命名和删除视频或图片；可重命名、删除整个素材组。
- 一个参考视频组最多上传一条参考视频；产品图片组可上传多张图片。
- 上传时检查文件类型和大小，文件不符合要求时给出明确提示。
- 删除素材组时说明组内素材会一并删除，并要求用户确认。

验收要点：素材上传后可预览，刷新后仍存在；视频不能上传到图片组，图片不能上传到视频组。

### 3.3 参考视频与产品预览图

**用户目标：** 把较长的视频和多张产品图整理成便于检查、便于 AI 理解的画面。

功能要求：

- 从选定参考视频中按时间顺序抽取画面，并合成参考视频预览图。
- 将选定产品图片合成产品预览图，尽量保留图片原始比例。
- 两类预览图均可查看大图、生成新版本、切换版本和删除版本。
- 预览图与当前作品及其来源素材关联，不能混用其他作品的结果。
- 视频无法播放、图片无法读取或生成失败时，提示原因并允许重试。

验收要点：用户能辨认预览图的来源，且重新生成不会覆盖旧版本。

### 3.4 产品视频方案

**用户目标：** 沿用参考视频的拍法和节奏，得到适合自己产品的分镜方案。

功能要求：

- 选择参考视频预览图和产品预览图，可填写产品补充信息。
- 调用多模态模型，分析参考拍法并生成产品视频方案。
- 方案按 `Generation 1`、`Generation 2` 等生成段组织；每段包含后续生成图片和视频所需的画面、动作、时长及配音信息。
- 展示完整方案；支持重新生成、查看和选择不同版本，以及删除不需要的版本。
- 输入不完整、模型未配置、调用失败或模型无有效输出时，给出可理解的错误提示。

验收要点：方案能被拆分成明确的生成段，后续步骤能按生成段继续制作。

### 3.5 产品分镜关键帧

**用户目标：** 为每个生成段制作合适的首帧画面，并挑选满意的版本。

功能要求：

- 根据选中的方案生成关键帧提示词，并允许用户修改。
- 结合产品预览图调用图片模型，按生成段生成关键帧。
- 支持单段生成和全部生成；同一生成段可保留多个候选版本。
- 可预览、再次生成、编辑已有图片、选择或删除候选版本。
- 每个生成段最多选中一个用于视频生成的关键帧。
- 某一段失败时保留其他段已生成的结果，并允许单独重试。

验收要点：刷新后仍能看到候选版本和选中状态；视频生成使用的图片与所选版本一致。

### 3.6 分镜视频生成

**用户目标：** 把选中的关键帧转换成动态视频片段。

功能要求：

- 根据方案生成视频提示词，允许用户修改后提交任务。
- 将所选关键帧作为首帧，向视频模型提交异步生成任务。
- 显示排队、生成中、成功或失败状态；支持刷新任务状态和失败后重新生成。
- 生成成功后可预览视频；同一生成段可保留多个版本，并选择一个用于成片合成。
- 页面刷新后仍能恢复已保存的任务与结果。

验收要点：未选关键帧时不能误提交任务；失败任务不会显示为已完成；每段最终只使用一个选中的视频版本。

### 3.7 成片与剪映草稿

**用户目标：** 获得可直接使用的短片，或进入剪映继续调整。

功能要求：

- 所有生成段均有已完成且已选中的视频后，按生成段顺序合成完整 MP4。
- 使用 FFmpeg 处理片段；合成失败时展示错误，不产生虚假的成功记录。
- 保存多个成片版本，支持播放、下载和删除。
- 基于已选视频片段及方案中的配音文字生成剪映草稿，支持查看记录、复制草稿链接和删除记录。
- 剪映草稿依赖外部草稿服务，服务不可用或素材地址不可访问时应显示失败原因。

验收要点：下载的视频可正常播放，镜头顺序与方案一致；草稿成功后能取得可用链接。

### 3.8 批量生成与模型设置

**批量生成：** 用户可选择多个素材完整的同款素材组，按组依次完成参考预览图、产品预览图、视频方案、关键帧和分镜视频生成。界面展示每组及每步的执行状态；失败时停在出错步骤，已完成结果保留。批量流程在分镜视频完成后结束，最终成片由用户进入作品单独合成。

**模型设置：** 分别配置多模态、图片、视频模型的模型 ID、接口地址和 API Key。支持保存配置和测试连接；配置缺失时，相关生成操作应说明需要补充哪类模型。密钥不应出现在普通页面文案或错误提示中。

验收要点：批量任务能明确显示完成、进行中及失败的素材组；模型连接测试能区分成功与失败。

## 4. 通用体验要求

- 所有耗时操作显示执行状态，防止重复提交；成功和失败均给出反馈。
- 删除作品、素材和生成版本前，明确告知影响范围并二次确认。
- 列表为空时说明下一步操作；生成条件不足时说明缺少什么。
- 每个生成结果保留来源与版本信息，切换版本不应意外覆盖其他版本。
- 上传和生成的数据需要持久化，页面刷新后可以继续操作。
- 工作台应支持桌面和手机浏览，图片、视频预览不得溢出屏幕。

## 5. 使用前提与范围

- 运行环境需要 Node.js、SQLite 可写目录，以及 FFmpeg／FFprobe；合成成片依赖 FFmpeg。
- AI 方案、关键帧和分镜视频分别依赖已配置且可用的多模态、图片和视频模型服务。
- 剪映草稿依赖可用的外部草稿服务；远程服务读取本地媒体时，还需要可访问的素材地址。
- 当前产品以单用户、本地工作台为范围；账号登录、团队协作、云同步、支付和专业剪辑时间线不在本需求范围内。
- 仓库中部分旧文档和隐藏页面仍使用“十步流程”的描述。用户实际操作与本文件均以当前六步工作台为准。

## 6. 建议的 Vibe Coding 实施顺序

每完成一个模块，先按对应验收要点验证，再进入下一个模块：

1. 作品管理与素材管理：先确保数据可保存和读取。
2. 两类预览图：打通媒体输入与版本管理。
3. 模型设置与产品视频方案：先得到可检查的文字结果。
4. 关键帧与分镜视频：逐段生成、选择并恢复任务状态。
5. 成片与剪映草稿：完成最终交付流程。
6. 批量生成与移动端体验：在单个作品流程稳定后完善。
