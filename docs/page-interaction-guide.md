# AI Product Reel 页面交互说明

> 本文档用于说明 AI Product Reel 的页面结构、用户操作、状态变化和异常反馈，供产品设计、前端实现、测试验收及 Codex 教学使用。
>
> 配套文档：
>
> - [产品需求文档](./product-requirements.md)
> - [开发路线](./development-roadmap.md)

## 1. 交互目标

AI Product Reel 包含素材准备、AI 分析、图片生成、视频生成和后期导出等多个环节。页面交互设计需要帮助用户理解：

- 当前正在处理哪个作品。
- 完整流程包含哪些步骤。
- 当前步骤需要哪些输入。
- 哪些前置条件尚未完成。
- 一个操作正在等待、执行、成功还是失败。
- 一个 Generation 当前选中了哪个图片或视频版本。
- 下一步最合理的操作是什么。

产品应尽量降低用户对模型协议、数据库和 FFmpeg 等技术细节的感知，但错误发生时需要提供足够信息帮助用户处理问题。

## 2. 信息架构

### 2.1 一级页面

| 页面 | 路由 | 主要用途 |
| --- | --- | --- |
| 首页 | `/` | 查看作品、管理素材、批量生成 |
| 作品工作台 | `/workflows/{id}` | 完成单个作品的完整生成流程 |

### 2.2 首页功能区

首页包含三个主要入口：

1. 作品列表。
2. 素材库。
3. 批量生成。

### 2.3 作品工作台步骤

作品工作台按以下顺序展示：

1. 参考视频
2. 智能抽帧
3. 视频总览
4. 结构脚本
5. 产品参考
6. 故事板
7. 关键帧提示词
8. 关键帧图片
9. 视频提示词
10. 分镜视频

成片合成和剪映草稿作为流程收尾操作，展示在分镜视频之后。

## 3. 全局页面布局

### 3.1 桌面端布局

```text
┌──────────────────────────────────────────────────────────┐
│ 顶部栏：产品名称 / 当前作品 / 模型设置 / 批量生成         │
├────────────┬─────────────────────────────────────────────┤
│            │                                             │
│ 侧边导航   │ 主内容区                                    │
│            │                                             │
│ 作品       │ 作品列表 / 素材库 / 工作流步骤              │
│ 素材库     │                                             │
│ 步骤导航   │                                             │
│            │                                             │
└────────────┴─────────────────────────────────────────────┘
```

交互要求：

- 左侧导航保持稳定，不因主内容变化产生明显跳动。
- 主内容区使用合理最大宽度，宽屏下不应无限拉伸。
- 当前一级功能和当前工作流步骤需要有明显选中状态。
- 滚动工作流时，用户仍能知道当前所在步骤。

### 3.2 移动端布局

```text
┌──────────────────────────┐
│ 菜单  当前作品      设置 │
├──────────────────────────┤
│ 当前步骤 / 步骤切换      │
├──────────────────────────┤
│                          │
│ 主内容                   │
│                          │
└──────────────────────────┘
```

交互要求：

- 侧边导航改为抽屉菜单。
- 打开抽屉时锁定页面背景滚动。
- 选择导航项后自动关闭抽屉。
- 卡片、按钮和表单按单列排列。
- 图片和视频预览不得超出视口。
- 主要操作按钮触控区域不小于 44×44 像素。

## 4. 全局交互规则

### 4.1 加载状态

页面首次加载时：

- 列表使用骨架屏或明确的加载提示。
- 不显示“暂无数据”，避免把加载中误认为空状态。
- 多个区域并行加载时，各区域独立显示状态。
- 加载失败的区域允许单独重试，不要求刷新整个页面。

### 4.2 按钮状态

按钮分为以下状态：

| 状态 | 表现 | 是否可点击 |
| --- | --- | --- |
| 默认 | 显示动作名称 | 是 |
| 悬停 | 强化背景或边框 | 是 |
| 聚焦 | 显示清晰焦点环 | 是 |
| 禁用 | 降低对比度并说明原因 | 否 |
| 执行中 | 显示旋转图标和进行中文案 | 否 |
| 成功 | 恢复默认状态并显示成功提示 | 是 |
| 失败 | 恢复可操作状态并显示错误 | 是 |

耗时操作开始后必须立即禁用同一按钮，避免重复提交。

### 4.3 消息反馈

短时反馈使用 Toast：

- 创建、保存、删除成功。
- 文件上传完成。
- 已切换选中版本。
- 操作失败，但无需用户在弹窗中做决定。

Toast 建议停留 2.5～4 秒。错误内容较长或需要用户处理时，使用区域内错误卡片或弹窗，不只使用 Toast。

### 4.4 删除确认

所有会删除持久化数据的操作必须二次确认。

确认弹窗至少包含：

- 要删除的资源名称。
- 删除会影响的内容。
- “取消”和“确认删除”按钮。
- 删除执行中的不可重复提交状态。

删除按钮使用危险色，但不应将默认焦点放在“确认删除”上。

### 4.5 空状态

空状态必须回答两个问题：

1. 为什么这里没有内容？
2. 用户接下来可以做什么？

示例：

```text
还没有产品关键帧
请先选择一个产品视频方案，然后生成 Generation 1 的关键帧。
[去选择方案]
```

### 4.6 错误状态

错误提示采用“发生了什么 + 如何处理”的结构。

推荐：

```text
视频任务提交失败：视频模型尚未配置。请前往模型设置填写模型 ID、Base URL 和 API Key。
```

不推荐：

```text
Error 500
```

### 4.7 版本选择

预览图、方案、关键帧和视频都可能存在多个版本。

- 当前选中版本显示高亮边框和“已选择”标记。
- 点击候选卡片只切换查看版本，不应自动改变最终选择，除非界面明确写着“选择此版本”。
- 删除当前选中版本前需要提醒其影响。
- 同一 Generation 的关键帧最多选中一个。
- 同一 Generation 的视频最多选中一个。

## 5. 首页交互

### 5.1 进入首页

### 初始行为

1. 请求作品列表。
2. 请求素材组概要信息。
3. 默认显示“作品”区域。
4. 如果没有作品，显示创建引导。

### 页面状态

- 加载中：作品卡片骨架屏。
- 加载成功且有数据：作品卡片列表。
- 加载成功但为空：空状态和“创建第一个作品”。
- 加载失败：错误信息和“重新加载”。

### 5.2 作品列表

每张作品卡片展示：

- 作品名称。
- 创建或更新时间。
- 当前状态。
- 当前步骤或完成进度。
- 预览图、方案、关键帧和视频数量。
- “打开作品”主操作。
- 重命名和删除次要操作。

### 打开作品

1. 用户点击作品卡片或“打开作品”。
2. 跳转到 `/workflows/{id}`。
3. 显示工作台加载状态。
4. 校验作品存在后加载各步骤数据。

如果作品不存在，显示“作品不存在或已删除”，并提供返回首页按钮。

### 5.3 创建作品

### 触发

用户点击“新建作品”。

### 弹窗字段

- 作品名称，必填。

### 交互流程

1. 打开弹窗后自动聚焦名称输入框。
2. 输入内容后点击“创建作品”。
3. 空名称或纯空格时显示字段错误。
4. 提交时按钮显示“创建中”。
5. 成功后关闭弹窗并进入新作品。
6. 失败时保留用户输入，展示失败原因。

### 键盘行为

- `Enter`：表单有效时提交。
- `Escape`：未提交时关闭弹窗。
- 执行中不能通过重复按 Enter 再次提交。

### 5.4 重命名作品

1. 点击作品菜单中的“重命名”。
2. 弹窗预填当前名称并选中文字。
3. 名称未改变时允许取消，但不发送无意义请求。
4. 保存成功后更新卡片和作品页标题。

### 5.5 删除作品

确认文案应明确说明：

```text
确定删除作品“护肤精华广告”吗？
该作品的预览图、方案、关键帧、视频和成片记录也会被删除。
```

删除当前正在打开的作品后，返回首页并刷新作品列表。

## 6. 素材库交互

### 6.1 素材库首页

素材库按以下方式组织：

- 参考视频素材组。
- 产品图片素材组。
- 当前素材组中的文件。

用户先选择素材组，再查看和管理组内素材。

### 6.2 创建素材组

### 字段

- 素材类型：参考视频或产品图片。
- 素材组名称。
- 关联参考组：仅产品图片素材组显示，可选。

### 联动规则

- 选择“参考视频”后隐藏关联参考组。
- 选择“产品图片”后显示关联参考组选择框。
- 名称为空时不能提交。

### 6.3 上传素材

### 参考视频

- 文件选择器优先过滤视频类型。
- 支持拖拽上传时，拖入区域显示高亮。
- 单次上传前展示文件名和大小。
- 上传成功后立即加入素材列表。

### 产品图片

- 支持一次选择多张图片。
- 上传前展示缩略图和待上传数量。
- 每个文件显示独立成功或失败状态。
- 部分失败时保留已成功文件，并允许重试失败文件。

### 上传状态

```text
待上传 → 上传中 → 成功
                ↘ 失败 → 重试
```

### 校验反馈

- 类型不支持：说明允许的视频或图片格式。
- 文件为空：提示重新选择。
- 文件过大：显示限制和当前文件大小。
- 网络失败：保留待上传列表，允许重试。

### 6.4 素材预览

### 图片

- 点击缩略图打开大图查看器。
- 支持上一张、下一张和关闭。
- 显示文件名和尺寸信息。

### 视频

- 点击缩略图打开视频播放器。
- 支持播放、暂停、进度拖动、音量和全屏。
- 首次打开时不应自动播放有声音的视频。

### 6.5 素材操作

每个素材支持：

- 预览。
- 下载。
- 重命名。
- 删除。

素材组支持：

- 重命名。
- 修改产品组与参考组的关联。
- 删除素材组。

## 7. 作品工作台通用交互

### 7.1 进入工作台

进入 `/workflows/{id}` 后：

1. 读取作品信息。
2. 并行读取素材概要和各步骤已有版本。
3. 默认定位到第一个未完成步骤；若没有进度记录，则定位到步骤 1。
4. 页面标题显示当前作品名称。
5. 加载完成后再启用生成操作。

### 7.2 步骤导航

- 点击步骤名称，平滑滚动或切换到对应区域。
- 当前步骤使用高亮样式。
- 已满足前置条件的步骤显示完成标记。
- 未满足前置条件的步骤可以查看，但主操作处于禁用状态并显示原因。
- 用户不应因为误点后续步骤而丢失当前输入。

### 步骤状态

| 状态 | 表现 |
| --- | --- |
| 未开始 | 灰色序号 |
| 可开始 | 正常序号和主按钮 |
| 进行中 | 动画或进度标识 |
| 已完成 | 完成图标 |
| 失败 | 错误图标和重试入口 |

### 7.3 前置条件提示

禁用按钮附近必须显示具体原因，例如：

- “请先选择参考视频”。
- “请先生成参考视频总览图”。
- “请先选择产品预览图”。
- “请先生成产品视频方案”。
- “Generation 2 尚未选择关键帧”。

不应只通过降低按钮透明度表达不可用。

## 8. 步骤 1：参考视频

### 页面内容

- 参考视频素材组选择器。
- 当前组中的视频列表。
- 当前选择的视频播放器。
- “前往素材库”入口。

### 操作流程

1. 用户选择参考视频素材组。
2. 视频列表切换到该组内容。
3. 如果组内只有一个视频，默认选择该视频。
4. 用户点击视频后更新播放器。
5. 当前选择结果用于后续智能抽帧。

### 空状态

如果没有参考视频素材组：

```text
还没有参考视频
请先到素材库创建参考视频组并上传视频。
[打开素材库]
```

## 9. 步骤 2：智能抽帧

### 页面内容

- 当前参考视频概要。
- 抽帧说明。
- “生成视频总览图”按钮。
- 生成进度与错误区域。

### 操作流程

1. 用户确认参考视频。
2. 点击“生成视频总览图”。
3. 按钮变为“正在抽帧”。
4. 页面展示阶段性说明，例如“读取视频信息”“提取画面”“合成预览图”。
5. 成功后自动刷新步骤 3 的版本列表。
6. 页面提示成功，并提供“查看总览图”。

### 异常处理

- 视频文件不存在：提示重新选择或上传。
- FFmpeg 不可用：提示检查本地安装或环境变量。
- 视频损坏：提示更换文件。
- 生成超时：允许重新生成，不删除旧版本。

## 10. 步骤 3：视频总览

### 页面内容

- 大尺寸总览图预览。
- 历史版本列表。
- 当前查看版本的信息。
- 查看大图和删除操作。

### 版本交互

- 最新版本默认展示，但不强制覆盖用户之前选择。
- 点击历史版本更新主预览。
- 删除当前版本后，自动切换到剩余的最新版本。
- 没有剩余版本时恢复为空状态。

## 11. 步骤 4：结构脚本

### 页面内容

- 当前视频总览图。
- 分析提示词入口。
- “分析参考视频”按钮。
- Markdown 结果预览。
- 历史版本列表。

### 提示词编辑

1. 点击“编辑分析要求”。
2. 弹窗显示完整提示词。
3. 用户可以修改、恢复默认值或取消。
4. 保存只更新当前页面草稿，不自动发起模型请求。

### 生成流程

1. 校验多模态模型和总览图。
2. 用户点击“分析参考视频”。
3. 显示“AI 正在分析镜头结构”。
4. 成功后展示 Markdown 内容并保存新版本。
5. 失败时保留提示词，允许重试。

## 12. 步骤 5：产品参考

### 页面内容

- 产品素材组选择器。
- 产品图片缩略图列表。
- “生成产品预览图”按钮。
- 产品预览图版本区域。

### 操作流程

1. 默认选择与当前参考视频组关联的产品组。
2. 用户可以手动切换产品组。
3. 选择变化后刷新图片列表，但不自动生成。
4. 点击生成后合成产品预览图。
5. 成功后显示大图和历史版本。

如果产品组中没有图片，生成按钮禁用并提示“请先上传产品图片”。

## 13. 步骤 6：故事板

### 页面内容

- 参考结构版本选择。
- 产品预览图版本选择。
- 产品补充描述输入框。
- 故事板提示词入口。
- “生成产品视频方案”按钮。
- Generation 列表和原始 Markdown 查看方式。

### 生成前校验

必须具备：

- 已选择参考视频总览图或结构版本。
- 已选择产品预览图。
- 多模态模型配置完整。

产品补充描述可选，例如目标人群、卖点、材质或禁用元素。

### 结果展示

模型输出解析成功后，按 Generation 展示：

- 编号。
- 生成时长。
- 场景和构图。
- 商品状态。
- 镜头与主体动作。
- 关键帧生成描述。
- 视频生成描述。

解析失败时展示原始响应和“重新生成”，不得伪造 Generation 卡片。

## 14. 步骤 7：关键帧提示词

### 页面内容

每个 Generation 对应一个提示词卡片，包含：

- Generation 名称和时长。
- 默认图片提示词。
- 编辑按钮。
- “生成关键帧”按钮。
- 当前生成状态。

### 编辑交互

1. 点击某个 Generation 的“编辑提示词”。
2. 打开编辑弹窗并加载该段当前提示词。
3. 保存后只更新该 Generation。
4. 取消时丢弃未保存内容。
5. 再次生成使用最新保存内容。

### 批量操作

“生成全部关键帧”按 Generation 顺序执行：

- 已有关键帧的 Generation 默认跳过，除非用户选择重新生成。
- 每段独立显示状态。
- 单段失败后继续其他段。
- 用户可以在执行期间查看已完成结果。

## 15. 步骤 8：关键帧图片

### 页面结构

按 Generation 分组，每组包含：

- 候选图片列表。
- 当前选中图片。
- 大图查看。
- 上传替换。
- 重新生成。
- 删除。

### 选择关键帧

1. 点击候选图片进入查看状态。
2. 点击“选择此版本”后保存选择。
3. 该组其他版本自动取消选中。
4. 卡片显示“已选择”。
5. 步骤 9 和步骤 10 使用被选中的版本。

### 上传替换

- 用户可上传自行制作的关键帧。
- 上传图片仍然属于当前 Generation 的一个新版本。
- 上传成功后不默认替换选择，除非用户明确勾选“上传后选择”。

## 16. 步骤 9：视频提示词

### 页面内容

每个 Generation 展示：

- 已选关键帧缩略图。
- 视频时长。
- 默认视频提示词。
- 编辑按钮。
- “生成分镜视频”按钮。

### 状态规则

- 没有选中关键帧：按钮禁用。
- 视频模型未配置：按钮禁用并提供设置入口。
- 已有处理中任务：按钮显示任务状态，避免重复提交。
- 已有完成视频：允许重新生成候选版本。

## 17. 步骤 10：分镜视频

### 页面结构

按 Generation 分组展示视频候选版本。

每个版本显示：

- 视频播放器或占位状态。
- 任务状态。
- 生成时间。
- 使用的时长和提示词摘要。
- 刷新、重试、选择和删除操作。

### 视频任务状态

#### 排队中

- 显示“等待模型处理”。
- 提供手动刷新，但不允许重复提交同一任务。

#### 处理中

- 显示加载动画和“生成中”。
- 页面每隔合理时间自动刷新。
- 用户离开页面不取消任务。

#### 成功

- 显示播放器。
- 提供“选择此版本”和下载。
- 停止自动轮询。

#### 失败

- 显示可理解的错误原因。
- 提供“使用原提示词重试”和“返回编辑提示词”。
- 不自动删除失败记录，便于定位问题。

### 自动轮询规则

- 只轮询排队中或处理中的任务。
- 页面不可见时降低轮询频率或暂停。
- 单个任务失败不影响其他任务。
- 网络暂时失败时保留原状态，不立即标记模型任务失败。

## 18. 最终视频交互

### 合成前检查

点击“合成最终视频”时，系统检查：

- 是否已有产品视频方案。
- 每个必要 Generation 是否有选中视频。
- 视频文件是否仍然可用。

如果缺少内容，展示汇总，例如：

```text
暂时无法合成：
- Generation 2 尚未选择视频
- Generation 4 的视频文件不可用
```

### 合成流程

1. 点击“合成最终视频”。
2. 按钮显示“正在合成”。
3. 页面提示正在统一视频参数和拼接片段。
4. 成功后刷新成片列表，并自动展示最新版本。
5. 用户可以播放、下载或删除成片。

合成期间不锁死整个页面，用户仍可查看已有内容，但不能再次发起合成。

## 19. 剪映草稿交互

### 草稿配置

用户点击“生成剪映草稿”后打开配置弹窗，包含：

- 草稿名称。
- 草稿生成提示词。
- 当前最终视频。
- 可选视频、音频和图片附件。

### 附件上传

- 每个附件显示媒体类型、名称和大小。
- 视频和音频显示探测到的时长。
- 探测失败时提示该素材是否还能继续使用。
- 支持在提交前移除附件。

### 生成结果

- 创建中：显示进度状态。
- 成功：提供草稿地址和使用提示地址。
- 失败：保留配置与错误信息，允许重试。
- 历史草稿按创建时间倒序展示。

## 20. 批量生成交互

### 20.1 打开批量生成

用户从首页点击“批量生成”，打开独立弹窗或页面。

### 配置区

- 选择一个参考视频素材组。
- 选择一个参考视频。
- 多选产品素材组。
- 查看将要创建的作品数量。

### 提交前校验

- 至少有一个参考视频。
- 至少选择一个包含图片的产品素材组。
- 三类模型配置完整。
- 用户确认预计创建的作品数量。

### 20.2 进度展示

每个产品素材组显示一张进度卡：

```text
产品组：琥珀精华液

✓ 合成产品预览图
✓ 生成产品视频方案
● 生成产品分镜关键帧
○ 生成分镜视频

当前状态：执行中
```

状态图例：

- `○` 等待。
- `●` 执行中。
- `✓` 完成。
- `×` 失败。

### 失败处理

- 失败步骤显示错误摘要。
- 提供“重试失败步骤”。
- 已完成步骤不重复执行。
- 其他产品组继续运行。

### 完成状态

- 单个产品组完成后提供“打开作品”。
- 全部结束后显示完成数量和失败数量。
- 关闭弹窗后，作品列表自动刷新。

## 21. 模型设置交互

### 21.1 打开设置

模型设置使用弹窗或侧边面板，分为三个标签：

- 多模态模型。
- 图片模型。
- 视频模型。

每个标签包含模型 ID、Base URL 和 API Key。

### 21.2 API Key 展示

- 默认使用密码输入框。
- 支持按住或点击图标短暂显示。
- 服务端未返回真实密钥时，使用“已配置”状态表示。
- 用户不修改密钥时，保存其他字段不能清空已有密钥。

### 21.3 测试连接

1. 用户填写当前标签的配置。
2. 点击“测试连接”。
3. 按钮显示“测试中”。
4. 成功时显示服务可访问和模型是否可用。
5. 失败时区分地址错误、鉴权失败、模型不存在和网络超时。

测试连接不自动保存配置。保存和测试是两个独立动作。

### 21.4 保存设置

- 保存时校验三类配置结构。
- 支持暂时留空尚未使用的模型类型，但对应生成功能不可用。
- 保存成功后关闭弹窗或保留当前标签，并显示成功提示。
- 保存失败时保留用户输入。

## 22. 弹窗和查看器规范

### 22.1 通用弹窗

- 打开后焦点进入弹窗。
- `Tab` 焦点不能跑到背景内容。
- `Escape` 可以关闭非执行状态弹窗。
- 点击遮罩是否关闭需要保持全局一致。
- 执行中的关键操作不能因误点遮罩中断。
- 关闭后焦点返回触发按钮。

### 22.2 图片查看器

- 黑色或深色遮罩突出图片。
- 支持缩放或至少适应窗口。
- 左右方向键切换同组版本。
- `Escape` 关闭。
- 显示版本名称和选中状态。

### 22.3 视频查看器

- 支持常用播放控制。
- 切换视频时停止上一段播放。
- 关闭查看器时暂停视频并释放媒体资源。
- 视频加载失败时提供下载入口或重试。

## 23. 可访问性要求

- 所有图标按钮必须有可读的 `aria-label`。
- 输入框必须关联可见标签。
- 不使用普通 `div` 模拟按钮、链接或弹窗。
- 弹窗使用正确的对话框语义。
- 状态变化通过可访问的状态区域告知辅助技术。
- 不只使用颜色表达成功、失败和选中。
- 图片提供符合内容用途的替代文字。
- 视频如包含必要对白或信息，应支持字幕轨道。
- 键盘可以完成作品管理、版本选择和生成主流程。

## 24. 文案规范

### 24.1 按钮使用动作动词

推荐：

- 创建作品
- 上传产品图片
- 生成关键帧
- 选择此版本
- 合成最终视频
- 重试失败任务

避免：

- 确定
- 操作
- 下一步
- 提交

如果“下一步”不能准确表达将发生的动作，应使用具体动作名称。

### 24.2 进行中文案

推荐使用明确对象：

- 正在上传产品图片
- 正在分析镜头结构
- 正在生成 Generation 3
- 正在下载视频结果
- 正在合成最终视频

避免所有地方都只显示“处理中”。

### 24.3 错误文案

错误文案不直接展示冗长堆栈。开发环境可以提供“查看技术详情”，生产界面默认展示用户可理解的摘要。

## 25. 页面状态保存

### 必须持久化

- 作品名称和状态。
- 各类生成版本。
- 当前选中的关键帧和视频。
- 异步视频任务 ID 和状态。
- 最终视频和草稿记录。
- 模型配置。

### 可仅保存在前端

- 当前打开的弹窗。
- 图片查看器缩放比例。
- 当前设置标签。
- 尚未保存的提示词草稿。
- 当前 Toast。

### 建议保存在 URL

- 当前作品 ID。
- 必要时可增加当前步骤，例如 `?step=keyframes`。

将步骤写入 URL 后，用户刷新或分享链接仍能回到对应位置。

## 26. 异常恢复

### 页面刷新

- 已保存数据重新读取。
- 未完成视频任务恢复轮询。
- 本地未保存的弹窗输入可以丢失，但执行中任务不能丢失。

### 网络断开

- 保留当前内容。
- 暂停或延迟轮询。
- 显示连接异常。
- 网络恢复后允许重新加载状态。

### 服务重启

- SQLite 中的数据保持可用。
- 上游任务 ID 仍可继续查询。
- 临时文件丢失不会破坏已完成媒体记录。

## 27. Codex 页面实现顺序

建议按以下顺序让 Codex 实现交互：

1. 静态页面骨架和响应式布局。
2. 全局按钮、Toast、空状态和确认弹窗。
3. 作品列表及 CRUD。
4. 素材组、上传和媒体查看器。
5. 工作台步骤导航和前置条件。
6. 预览图版本交互。
7. 故事板及 Markdown 展示。
8. 关键帧提示词和版本选择。
9. 视频任务状态和轮询。
10. 成片、草稿和批量生成。
11. 键盘操作、可访问性和异常恢复。

每一步完成后先验证交互，再进入下一步，不应先把所有按钮接到接口后才处理状态和错误。
